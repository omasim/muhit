# Muhit 0.18.0 — güncel kabul kapsamı

Muhit; ilkeler, tema/token grafiği, ortak etkileşimler, 30 bileşen sözleşmesi, 8 kullanım örüntüsü, 6 sayfa tarifi ve AI kompozisyon incelemesini aynı sürümde birleştirir. Yeni sistem katmanları beta; önceki 18 Agent türü ve API girişleri korunur.

Çalıştırılabilir referanslar: sistem stüdyosu, kurumsal site, yönetim uygulaması ve veri uygulaması (`examples/system/`). Örneklerin verisi kurgudur. Kalıcı backend, kullanıcı kimliği ve server authorization ürün entegrasyonunun sorumluluğudur.

Doğrulama kapıları: 82 Node testi, 80 public paket tip girişi, mevcut üç motorlu CI, 16 yeni responsive/axe taraması, menü/tree/tooltip klavyesi, iptal, taslak koruma, AI onayı, toplu kısmi sonuç/yeniden deneme, çok adımlı geri dönüş ve import önizlemesi. Test sayıları kabul hedefidir; gerçekten çalıştırılmış sonuçlar [0.18 raporunda](SYSTEM-VERIFICATION-0.18.md) ve sürüm kanıtlarında ayrılır. Eski rapor bir sonraki sürümün kanıtı değildir.

Figma: [dosya ve sınırlar](FIGMA.md). 16 koleksiyon, 2.960 değişken, 30 aile/49 tasarım örneği, 6 sayfa kompozisyonu; kapsam bütün etkileşimlerin prototipi değildir. Starter takımında Dev Mode Code Connect yayımlanmadı.

Açık kabul: manuel VoiceOver/NVDA/JAWS ve fiziksel iOS/Android. Otomatik axe sonuçları erişilebilirlik sertifikası değildir. npm registry yayını ayrı yetki gerektirir; indirilebilir TGZ aynı şey değildir. React/Vue adaptörleri referans kodudur, bağımsız framework paketleri değildir. 1.0 kararlılık garantisi verilmez.
