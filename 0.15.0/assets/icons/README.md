# Muhit Icons 1.1.0

58 hand-authored outline SVG icons distributed under the repository MIT license. Canonical API geometry: src/icons.js; catalog: schemas/icons.json. Individual SVG files must match the API. Geometry is independent of the locked Muhit logo.

24 × 24 viewBox, currentColor, round caps/joins, 1.75 default stroke. Use inline SVG to inherit text/theme color; an external img does not inherit currentColor from its host. Accessible names belong to the icon-only control or a meaningful standalone icon. See docs/ICONS.md.
